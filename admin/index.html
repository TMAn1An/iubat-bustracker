      Add stops in bulk

      One stop per line, in driving order (far end first). A pick-up time at the end is optional. Don't include Campus; it is added automatically. Each stop is then looked up on OpenStreetMap near this route. Check every marker; anything not found is marked and can be placed by clicking the map.

      Tracker token

      Shown only once. Open the link on the bus phone (or paste the token into the tracker page) to start sharing location. Generating a new token disables the old one.
